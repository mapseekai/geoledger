# 认证重构修复与三轮复审验收

日期：2026-10-14。基线：`main / 1f0a7ac` 及其上的认证重构工作树。本记录对应四轮审查之后的修复与三轮复审，当时的存储格式为 16。代码与文档保留在本地工作树，提交、推送和生产部署分别执行；现有业务数据库和运行实例保持原状。

## 最终认证与资源契约

Console 支持用户名密码和 API Key 登录，浏览器使用安全 Cookie 保存加密 Session 标识。四语言 SDK 与 CLI 使用 API Key；HTTP 和 gRPC 共用数据库身份验证及项目 RBAC。用户 UUID 保持稳定，凭证和用户状态逐请求复核。

认证读取、密码计算、阻塞任务排队及写事务使用同一个请求截止时间。工作任务开始时计算剩余预算，事务准入与提交前检查期限；阻塞任务持有执行许可直到实际完成。认证响应在事务提交前完成受限编码与共享预算预留，响应体持有租约直到消费或释放。

用户状态分页使用 `(status,id)` 索引，并为有筛选、无筛选分别选择参数化 SQL。列表读取七个公开字段；只读认证操作复用初始事务。Session 活动时间更新在 SQL 中复核一分钟阈值，API Key 最近使用按五分钟阈值更新；涉及 Key 与 Session 的写入保持相同锁顺序。

SpatiaLite 连接由生命周期包装持有，查询使用共享访问 guard，初始化与析构使用独占保护。正式默认构建的 Application 使用可信身份入口；裸 subject fixture 入口通过非默认 `test-support` 和测试依赖隔离。

## 三轮复审及新增修复

审查实际使用本机 rust-pro、rust-async-patterns、golang-pro、golang-testing、frontend-patterns 和 Ponytail Review 规则，并阅读修改函数、调用者、SQL 与测试。

第一轮检查架构、规范和跨端一致性。发现并修复三处边界：非法 feature JSON 在 save、resolve、rebase 中统一返回确定的参数错误；浏览器在 HTML、空体或 null 错误响应下保留 HTTP 状态和登录跳转；BFF 使用严格 UTF-8 解码，非法字节及 BOM 按 JSON 输入规则拒绝，合法中文与 emoji 分块保持完整。新增三项回归先失败，修复后连同发布函数链共四项通过。当前格式文档同步至 16，并增加与引擎常量比较的文档检查；历史测量保留原版本。

第二轮检查内存、安全和并发。发现阻塞队列等待没有计入认证准入期限，修复为 worker 实际开始时按绝对 deadline 计算剩余时间。单 blocking worker 的受控回归覆盖 HTTP API Key、HTTP Session、gRPC API Key：过期任务返回 504，存储调用次数为零，执行许可释放。修复前该回归错误进入存储并返回 401，修复后通过。

第三轮检查最终功能、性能与测试有效性，未发现新的可证明产品缺陷。复审时全量回归曾遇到 JSON 字段功能测试的五秒夹具期限；该测试单独运行 0.04 秒通过，夹具改用引擎常规三十秒预算，功能断言与生产期限保持原样。最终默认并行全仓与 PostGIS 回归退出 0。专门的一秒 deadline 回归保持原约束。

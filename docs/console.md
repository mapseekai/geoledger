# 管理控制台

[项目概览](../README.md) · [启动与配置](../web/README.md#本地启动) · [协作指南](user-guide.md)

控制台通过项目、数据集、工作区和版本历史组织空间数据编辑。本指南以新增监测点为例，介绍从登录到发布、协作与撤销的完整操作。

## 启动与登录

按 [Web 本地启动](../web/README.md#本地启动) 启动业务服务和控制台。默认浏览器地址为 `http://localhost:3000`，业务服务 gRPC 地址为 `http://127.0.0.1:7882`。

在登录页的“访问令牌”中填写管理员分配的静态令牌或 JWT，点击“进入控制台”。默认本地服务的管理员凭证位于启动时生成的 `geoledger-data/admin-credentials.json`，选择对应用户的 `token` 字段。

控制台接受 1–2000 个可打印且非空白的 ASCII 字符。令牌保存在加密、签名的 HttpOnly/SameSite=Strict Cookie 中，会话有效期为 8 小时，HTTPS 下启用 Secure。每次业务请求由服务端核验身份和权限。

## 页面导航

可直接从侧栏进入数据集、工作区或版本历史：页面恢复本次会话已选择的项目；首次进入时使用授权项目列表中的第一个项目，并在地址栏和侧栏显示当前项目。通过“项目”列表可切换项目。显式指定的项目无效或无权限时显示错误，不会静默切换到其他项目；退出登录会清除当前项目偏好。

| 页面 | 用途 |
|---|---|
| 项目 | 创建项目、选择项目、筛选当前页项目 |
| 数据集 | 创建数据集、浏览和编辑 GeoJSON 要素 |
| 工作区 | 检查变更与冲突、发布、解决冲突、更新基准、丢弃草稿 |
| 版本历史 | 查看版本说明、发布者、发布时间和要素变更，创建撤销工作区 |
| 访问权限 | 按成员身份设置 owner/editor/viewer 角色 |
| 审计日志 | 项目所有者查询操作人、时间和事件详情 |
| 服务信息 | 查看版本、存储后端、存储格式和请求规格 |

侧栏项目区域返回项目列表；手机页面通过顶部菜单展开导航。页面中的 `r` 表示项目修订，`v` 表示工作区编辑版本。

## 添加第一条要素

1. 在“项目”中点击“创建项目”，名称填写“城市监测”。
2. 点击项目名称，在“数据集”中创建“监测点”。
3. 点击“浏览要素”，进入该数据集。
4. 点击“新建工作区”，页面自动选择新工作区。
5. 点击“添加要素”，要素标识填写 `station-001`。
6. 粘贴以下 GeoJSON，点击“保存到工作区”。

```json
{
  "type": "Feature",
  "id": "station-001",
  "properties": {
    "name": "滨江监测点",
    "category": "水质",
    "status": "正常"
  },
  "geometry": {
    "type": "Point",
    "coordinates": [120.15, 30.25]
  }
}
```

`properties` 保存业务属性，`geometry` 保存几何。此例的坐标为 `[经度, 纬度]`，使用 EPSG:4326。正文中的 `id` 与“要素标识”一致；省略正文 `id` 时界面自动补齐。

保存后，要素进入工作区草稿，工作区编辑版本随之增加。保存使编辑持久化为草稿，发布将草稿纳入共享数据版本。

## 浏览、编辑与删除

数据集要素页是一个地图工作台：中间为地图，左侧“图层与要素”，右侧“要素信息”，底部可打开属性表。工具栏的“数据来源”选择框可选择“已发布的数据”或自己的编辑中工作区，并支持输入工作区标识搜索；工作区视图包含基础版本与当前草稿修改。

- 地图按几何类型着色：点为橙色、线为蓝色、面为绿色，选中要素以黄色高亮。左侧图层树可按点、线、面分别显示或隐藏。
- 点击地图上的要素、列表行或属性表行即可选中，三处同步高亮；悬停时地图显示要素标识。点击地图空白处取消选择。
- 右侧“要素信息”显示属性、几何类型、部件数、顶点数和范围，可展开 GeoJSON 原文；未选择要素时显示图层的要素数、类型统计、坐标系和范围。
- 地图右上角提供放大、缩小、缩放至图层、全屏和底图切换。默认底图为本地纯色（浅色或深色），无需外网；管理员配置 `GL_WEB_BASEMAP_URL` 后可切换“在线地图”。左下角为比例尺，右下角显示光标经纬度（WGS 84）和缩放级别。
- 在“要素信息”中点击“缩放至要素”、“编辑”或“删除”。编辑修改属性或几何，点击“保存到工作区”；删除确认后在当前工作区保存删除意图。
- 在“数据来源”中输入完整工作区标识，选择“使用工作区”即可加载列表以外的工作区。列表提供前 100 个工作区，工作区页面还可分页查找。
- 底部属性表可拖动或用键盘方向键调整高度。手机和平板上，通过工具栏右侧按钮打开图层面板、属性表和要素信息。

地图一次加载最多 1000 个要素，超出时在列表底部点击“继续加载”。已发布数据的分批加载固定在同一修订，工作区草稿在加载期间发生变化时提示刷新。搜索匹配要素标识、属性名和属性值，同时过滤列表、属性表和地图；列表与属性表每页 100 条。GeoJSON 读取、展示、编辑和保存保留数字精度，包括 64 位整数；坐标不是有效经纬度或没有几何的要素仍在列表中显示，并标注“坐标无效”或“无几何”。

## 检查与发布

进入“工作区”，通过“版本图 / 表格”切换视图，默认显示版本图。两个视图共用工作区查找、新建和编辑操作；切换不会修改数据。基准 `rN` 表示草稿依据的项目版本，编辑版本 `vN` 是编辑计数，不是历史草稿快照。

版本图采用 GitGraph 式多轨道布局，每页从上到下按旧到新排列，默认加载最近 20 个版本，使用“更早 / 较新”翻页。连续发布沿同一路线延续；合并时来源基线所在路线延续，被合入的中间版本及其节点排在支线上。例如 `r3` 基于 `r1` 合入时，`r2` 显示在支线，主线不在同一行重复画点。每条发布记录显示版本、提交说明、提交人和时间，点击版本查看实际变更。来源详情可展开完整工作区标识，只有本页可访问的个人工作区提供选择操作。未发布工作区在提交记录之后以“草稿 / 未提交”和空心节点显示，不伪装成提交；页外基线明确标注，不连接到错误版本。基线是工作区当前基准（更新基准后会变化），不是完整的工作区创建和编辑历史。可点击草稿行、通过完整标识查找或切到表格操作；图内不再重复显示工作区选择器和顶部 HEAD。

1. 点击“变更”，检查新增、修改和删除内容。
2. 点击“发布”，填写版本说明，如“新增滨江监测点”。
3. 点击“确认发布”，成功后显示“版本 rN 已发布”。
4. 返回数据集，选择“已发布的数据”并重新加载，确认共享结果。

数据集页面的“发布版本”使用相同流程。工作区属于项目，可包含多个数据集的修改，发布时这些修改原子提交为一个项目修订。下一批编辑创建新的工作区。

## 冲突解决与更新基准

当多人修改同一要素时，服务按属性进行三方合并。不同顶层属性可以自动合并，同一属性的不同修改需要选择；几何作为一个整体比较。

1. 点击工作区的“冲突”，或在“更多”中选择“解决冲突”。
2. 左侧选择要素，右侧对比“已发布”和“我的草稿”。逐个冲突字段选择要保留的值；其他字段自动合并。
3. 新增、删除或过期的解决结果需要确认整个要素。“采用…整个要素”会替换该要素的全部字段；一侧已删除时，选择该侧就是确认删除。
4. 检查结果预览，点击“保存解决”。每页最多 20 个冲突，先保存本页选择再翻页；剩余冲突会重新加载。
5. 全部解决后检查变更，再发布。保存解决本身不会发布。

原始要素与基线默认折叠。“高级编辑未转义 GeoJSON”可输入完整 Feature 正文，再点击“采用高级结果”；不需要编写编辑数组或转义双引号。数字精度、缺失属性与 `null` 保持不变。

“更新基准”使用同一审阅界面。有冲突时先分批保存解决，剩余为零后点击“更新基准”；无冲突时可直接更新。保存解决与更新基准是独立操作，后一步失败不会撤销前面已经保存的解决结果。

审阅期间项目或草稿变化时，旧选择不会覆盖新内容；界面重新加载并要求确认。网络中断导致结果不确定时，先查看重新加载后的剩余冲突，不自动重试旧写入。只读查看不提供解决操作。


## 发布结果确认与恢复

首次发布前，浏览器在当前标签页保存项目、工作区、编辑版本、说明和请求 ID。连接中断或响应超时后：

1. 恢复连接，必要时重新登录。
2. 打开“工作区”，点击“重试原发布”。
3. 使用原请求确认结果，再继续编辑。

已提交的原请求返回保存的发布结果。刷新和会话过期后发布意图仍可恢复；主动退出会清除当前标签页的发布意图，因此先确认结果再退出。

## 查看历史与撤销

“版本历史”展示修订号、说明、发布者和时间，“详情”显示该版本的要素变更。

点击目标版本的“撤销”后，选择“创建撤销工作区”，再前往工作区检查反向修改并发布。撤销按所选提交生成反向编辑，保留其他版本的变化；原版本和审计继续保存在历史中。

## 团队权限与审计

项目所有者在“访问权限”填写成员 subject，选择角色后点击“保存权限”。subject 是令牌配置或身份提供方中的用户标识，例如 `alice`；成员的登录凭证由管理员配置。

| 角色 | 能力 |
|---|---|
| viewer | 浏览与查询共享项目数据和历史 |
| editor | 创建数据集、管理自己的工作区、编辑和发布 |
| owner | 编辑、发布、管理成员权限并查看审计 |

“访问权限”同时列出项目成员，owner 可移除成员（项目保留至少一名 owner），并在“项目状态”中归档或恢复项目；删除项目需输入项目名称确认，删除后项目从列表隐藏。归档项目保持只读。

审计页面展示事件编号、操作类型、成员和时间，“查看”可展开事件详情。权限由业务服务统一校验，界面按当前角色提供操作入口。

## 丢弃草稿与退出

工作区“更多 → 丢弃工作区”经确认后清理该工作区的未发布编辑，已发布历史继续保留。结束使用时，先确认待处理发布，再点击侧栏底部的退出图标。

## 界面与验证

控制台采用深色侧栏、顶部面包屑、统计卡片与表格面板，手机页面使用抽屉导航。字体和 SVG 标志随 Web 本地打包。页面使用 nonce CSP、no-store 缓存策略和固定 Origin 校验。运行配置与设计说明见 [Web 文档](../web/README.md)，回归与截图生成见 [浏览器验证](development.md#控制台浏览器验证)。

### 上传 GeoJSON 文件

在数据集要素页选择可编辑工作区，点击“添加要素”，通过“上传 GeoJSON 文件”选择 `.geojson` 或 `.json` 文件。支持单个 Feature、非空 FeatureCollection，以及标准几何对象。读取成功后显示文件名和要素数量，点击“保存到工作区”分批保存全部要素，发布后生效。已有相同标识的要素会被更新。

不限制文件大小或总要素数量，按请求体大小分批写入，每批最多 20 个要素；文件、单要素和请求/响应均不设应用层固定字节上限。缺少 id 时生成 UUID；数字 id 无损转换为字符串；null 属性转换为空对象。保留属性数字精度，导入几何与属性，不保存 bbox 和顶层扩展成员。文件解析失败时不写入。分批保存中断时保留已完成批次并显示数量，重试从未完成批次继续；响应丢失或并发编辑导致版本冲突时，需刷新检查工作区。浏览器可处理的实际大小取决于设备可用内存。

### 按数据集查看要素变更

工作区版本图、工作区表格和版本历史显示各数据集的新增、删除、修改要素数量，多数据集变更同时显示合计。工作区统计比较当前草稿与其基线，版本历史统计读取该次发布保存的变更记录；一个要素修改多个属性仍计为一次修改。点击“变更”或“详情”，可查看带数据集名称的统计表，统计覆盖全部变更分页，与详情当前页无关。统计过程中发生并发编辑会提示刷新，不显示混合编辑版本的计数。

创建数据集时选择点、线或面，创建后类型不可更改。项目和数据集列表提供重命名与删除入口，删除需要输入对应名称确认。删除数据集时，共用工作区或版本内其他数据集的记录会保留，清理后为空的关联记录才删除；删除项目会清除其全部数据、工作区和版本历史。

GeoJSON 上传默认使用 WGS84 经纬度；显式声明 EPSG:3857 的文件会转换为 WGS84，并显示提示，属性数值和高度不被转换。未知坐标系会提示先转换，不猜测坐标系。文件中不符合数据集几何类型的要素会在开始分批保存之前报错。

大文件在独立 Web Worker 中解析，保留属性数字精度；分批上传可写入同一工作区，不再限制累计 1000 个要素。服务端对自相交等拓扑问题返回警告并按原始坐标保存，导入界面显示警告数量及示例，审计记录保留对应要素标识和原因。

连接与工作上下文

令牌仅保留在当前页面内存中。每位测试用户使用独立令牌。

  1. 创建项目和数据集。
  2. 由项目所有者添加协作成员。
  3. 每个用户创建自己的草稿。
  4. 保存要素、查看差异，再发布。
  5. 遇到冲突，提交对应的解决结果后再次发布。
测试说明

这是 API 测试台。要素以 GeoJSON 编辑，保存进入个人草稿，发布才更新 PostGIS 正式要素。两个浏览器窗口可分别使用不同用户令牌，共享项目并验证多人编辑。
